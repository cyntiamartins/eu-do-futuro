# Eu do Futuro

Assistente de vida com IA. *Crescendo um dia de cada vez.*

A pessoa conta onde está (Roda da Vida), define onde quer chegar em 90 ou 100 dias, recebe uma tarefa mínima diária e todo dia o **Eu do Futuro** aparece na tela com a meta, os dias que faltam e um sinal de urgência. O **Método de Excelência Diária** transforma 7 pilares em missões práticas, uma por dia da semana.

## Versão atual: v1.0.0 (MVP local)

- Funciona no navegador e pode ser instalado na tela inicial do celular.
- Dados ficam no próprio aparelho. Login e nuvem chegam na Fase 3.

## Como atualizar

1. Edite `app.html`.
2. Rode `./build.sh` para gerar `index.html`.
3. Envie para o GitHub. O GitHub Pages publica sozinho.
